### Структура
generate_data.py отвечает за:
1. Получение квази решения
2. Получение численных решений
3. Создание и обучение сеточной модели
6. Создание и обучение модели, у которой граничные условия сеточные, а точки
   проверки уравнение выбираются LHS методом
7. Сохранение всего выше

visualize_data.py отвечат за:
1. Загрузку данных, полученных из generate_data.py
2. Получение PINN-решений
3. Построение графиков решений
4. Получение абсолютных ошибок решений относительно квази решения
5. Вывод в коносоль относительных ошибок
6. Визуализация точек, выбранных для обучения

### Использование
Запуск скрипта start.sh
#### Режимы
**generate**(без указание режима) - генерация данных
**visualisze** - визуализация готовыз данных
**all** - генерация и визуализация данных
#### Настройка
Для настройки используются следующие переменные окружения
**DATA_OUTPUT** - файл, используемый для генерации или визуализации данных
**MODEL_LAYERS_NUM** - количество слоёв
**MODEL_LAYERS_WIDTH** - количество нейронов в слое
**QUASI_SPACE** - количество пространственных интервалов в квази решении
**INITIAL_COUNT** - количество точек начального условия или `all`, по умолчанию все
**BOUNDARY_COUNT** - количество боковых граничных точек, использующихся в обучении
**COLLOCATION_COUNT** - количество точек, на которых проверяется уравнение
**ADAM_EPOCHS** - количество эпох основного обучения
**LBFGS_ITERS** - количество эпох дообучения
**ALTERNATIVE_COLLOCATION_COUNT** - количество LHS-точек для альтернативного PINN-варианта
**ALTERNATIVE_ADAM_EPOCHS** - количество эпох Adam для альтернативного PINN-варианта
**ALTERNATIVE_LBFGS_ITERS** - количество эпох LBFGS для альтернативного PINN-варианта
**STEPS** - количетсво итераций
**N_START** - начальное количество пространственных интервалов

Для визуализации выбранных initial/boundary точек используйте:
`./start.sh visualize --plot-training-points`
